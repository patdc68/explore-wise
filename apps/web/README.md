# ExploreWise web

Public marketing, legal, and support website for ExploreWise.

## Local development

```bash
npm install
npm run dev
```

The development server runs at [http://localhost:3000](http://localhost:3000).

## Validation

```bash
npm run lint
npm run typecheck
npm run build
```

## Deployment

Deploy this app as an independent Next.js project with `apps/web` as the
Vercel Root Directory. No environment variables or backend connection are
required for the current marketing-only milestone.
